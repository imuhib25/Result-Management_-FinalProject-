# Student Result Management System

A simple **Student Result Management System** written in **C** that reads student records from an input text file, calculates the weighted CGPA for each student, and stores the formatted results in an output text file.

## 📌 Project Overview

This project demonstrates fundamental C programming concepts, including:

* Structures
* Arrays
* Loops
* File handling
* Formatted input/output
* String handling
* Arithmetic calculations

The program can process up to **100 students** and calculates their CGPA based on the GPA of three courses.

## 🎯 Project Objective

The objective of this project is to develop a C program that can efficiently manage student academic results.

The program:

1. Reads student information from `student_input.txt`.
2. Stores the information using a structure array.
3. Calculates the weighted CGPA for every student.
4. Writes the calculated results to `output.txt`.

## 🧮 CGPA Calculation

The program calculates CGPA using a weighted average:

```text
CGPA =
((CSE103 GPA × 4.5) +
 (MAT101 GPA × 3.0) +
 (ENG7101 GPA × 3.0))
 / 10.5
```

For example, if a student has:

```text
CSE103  = 3.80
MAT101  = 3.50
ENG7101 = 3.90
```

The CGPA is:

```text
((3.80 × 4.5) + (3.50 × 3.0) + (3.90 × 3.0)) / 10.5
= 3.72
```

## 🔧 How the Program Works

### 1. Structure Declaration

The program uses the following structure:

```c
struct studentData
{
    int s_ID;
    char name[100];
    float gpa_CSE103, gpa_MAT101, gpa_ENG7101, t_CGPA;
};
```

This structure stores all information related to a student.

### 2. Structure Array

An array of 100 structures is created:

```c
struct studentData stdList[100];
```

This allows the program to store information for multiple students.

### 3. Opening Files

The program opens the input file in read mode and the output file in write mode:

```c
ptr1 = fopen("student_input.txt", "r");
ptr2 = fopen("output.txt", "w");
```

### 4. Reading Student Data

The number of students is read first:

```c
fscanf(ptr1, "%d", &n);
```

Then the program reads each student's information using `fscanf()`.

### 5. CGPA Calculation

For every student, the program calculates the weighted CGPA:

```c
stdList[i].t_CGPA =
    ((stdList[i].gpa_CSE103 * 4.5)
    + (stdList[i].gpa_ENG7101 * 3)
    + (stdList[i].gpa_MAT101 * 3)) / 10.5;
```

### 6. Writing Results

The calculated result is written to `output.txt` using `fprintf()`:

```c
fprintf(ptr2, "... Calculated CGPA: %.2f\n", ...);
```

### 7. Closing Files

Finally, both files are closed:

```c
fclose(ptr1);
fclose(ptr2);
```
